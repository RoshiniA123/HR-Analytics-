# 📊 HR Analytics | Power BI

## 🎯 Objective

The objective of this project is to analyze Human Resources (HR) data to uncover workforce trends, employee attrition patterns, job satisfaction, and performance metrics. The interactive Power BI dashboard enables HR managers and business leaders to make data-driven decisions that improve employee retention, workforce planning, and organizational performance.

---

## 📖 Project Overview

This project transforms raw HR data into an interactive Power BI dashboard using Power Query, DAX, and data modeling techniques. The dashboard provides actionable insights into employee demographics, attrition rates, department performance, job roles, and overall workforce distribution.

---

## 📊 Key Insights

- Identified departments with high employee attrition.
- Analyzed employee demographics and workforce diversity.
- Evaluated job satisfaction across different job roles.
- Tracked workforce distribution by department and education.
- Built an interactive dashboard for HR reporting and analysis.
